# Getting-and-Cleaning-Data-Course-Project
This repository contains the code book run_analysis.R required by the assignment. The data used in this project are collected from the accelerometers of the Samsung Galaxy S smartphone.

Files in the repository:
1. run_analysis.R: This R script performs the following step:
  - Merges the training and test sets to create one data set.
  - Extracts only the measurements on the mean and standard deviation for each measurement.
  - Uses descriptive activity names to name the activities in the data set.
  - Appropriately labels the data set with descriptive variable names.
  - Creates a second, independent tidy data set with the average of each variable for each
    activity and each subject.

2. CodeBook.md: This describes the variabels, data, and any transformations or work that was performed to clean up the data

3. FinalData.txt: This contains the final data set with the average of each variable for each activity and subject
